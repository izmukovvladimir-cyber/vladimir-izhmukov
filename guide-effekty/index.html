Видео и монтаж

Четыре эффекта монтажа через Claude Code: ты поверх экрана, заголовок с картинками, нарезка и текст за головой

Четыре эффекта монтажа из моего ролика собираются в Claude Code на твоём компьютере: ты поверх записи экрана, ты на весь экран с заголовком и парящими картинками, длинное видео, порезанное на короткие с заголовками и субтитрами, и текст за головой с эффектом глубины. Под капотом бесплатный инструмент HyperFrames: он вырезает тебя из фона, расставляет субтитры по словам и рендерит ролик в MP4. Внутри установка, схема слоёв, готовый запрос к Claude Code на каждый эффект, приёмка по кадрам и разбор того, где этот монтаж ломается.

HyperFrames это открытый движок от HeyGen: ролик описывается как веб-страница (HTML, CSS и анимации GSAP), а движок превращает её в видео. У него есть команды для ИИ-агентов: вырезка фона локальной моделью, распознавание речи с таймингом каждого слова и рендер в MP4. Claude Code пишет страницу ролика сам, ты даёшь ему файлы и запрос. Видео остаётся у тебя на компьютере.

Один раз ставишь инструменты из второго раздела, это около двадцати минут. Дальше на каждый ролик: кладёшь видео в папку, вырезаешь фон одной командой, вставляешь в Claude Code запрос нужного эффекта и принимаешь черновик по кадрам из раздела приёмки.

1. Как устроен каждый эффект: слои

Любой из четырёх эффектов это стопка слоёв, как в фотошопе. Нижний слой фон, верхний слой ты без фона. Всё, что встаёт между ними, оказывается за тобой, а всё, что ставится сверху, перед тобой. Поймёшь стопку, и любой эффект собирается из одних и тех же деталей.

Слой 1. Фон

Исходное видео, запись экрана, размытый кадр или однотонная заливка. Всё, что лежит позади.

Слой 2. Середина

Заголовок, карточки, текст глубины. Если поставить его ниже слоя с тобой, он окажется за твоей головой.

Слой 3. Ты без фона

Файл person.mov с прозрачностью в папке проекта. Его делает команда remove-background, вырезая тебя из исходника кадр за кадром.

Слой 4. Сверху

Субтитры по словам, плашка с названием эффекта, призыв в конце. Они всегда перед тобой и всегда читаются.

Эффект глубины получается из одной вещи: текст стоит на слое 2, а ты на слое 3. Если текст случайно уехал на слой 4, это обычная надпись поверх видео, и магии нет.

2. Установка, один раз

Нужны четыре вещи: Claude Code, Node.js версии 22 или новее, FFmpeg и сам HyperFrames. Распознавание речи ставится отдельно, оно нужно для субтитров по словам.

  1. Поставь Claude Code по инструкции на claude.com/claude-code и войди в аккаунт с подпиской Pro или выше.
  2. Поставь Node.js 22 с nodejs.org и FFmpeg (на Mac через brew install ffmpeg, на Windows через winget install ffmpeg).
  3. Открой терминал в пустой папке под ролики и выполни команды проверки ниже.
  4. Установи навыки HyperFrames для Claude Code: после этой команды Claude знает, как писать страницу ролика и как её рендерить.
  5. Для субтитров по словам поставь whisper.cpp, команда doctor сама подскажет, как это сделать на твоей системе.
Команды в терминал
node -v ffmpeg -version npx hyperframes doctor npx hyperframes skills
Команда doctor показывает зелёными галочками всё, что готово, и крестиком то, чего не хватает, с готовой строкой установки. Пункты про TTS и музыку для этих эффектов не нужны, их пропускай.

3. Подготовка исходника: вырезка и слова

Эти шаги делаешь для каждого ролика до любого эффекта. Команда init создаёт папку проекта, кладёт туда твоё видео под именем video.mp4 и пишет файл CLAUDE.md с правилами для Claude Code, поэтому Claude запускай из этой папки. Снимай на однотонном фоне и не обрезай руки краем кадра: всё, что не попало в кадр, вырезка не вернёт.

Создать проект и положить видео
npx hyperframes init moy-rolik --resolution portrait --video video.mp4 --skip-transcribe --non-interactive
Вырезать тебя из фона
npx hyperframes remove-background video.mp4 -o moy-rolik/person.mov
Слова с таймингом для субтитров (русская речь)
npx hyperframes transcribe video.mp4 -d moy-rolik -m large-v3 -l ru
Вырезка идёт на процессоре, у меня 31 секунда видео заняла около семи минут. Модель по умолчанию small.en понимает только английский, поэтому для русской речи ключи -m large-v3 -l ru обязательны.

4. Face Over Screen: ты поверх записи экрана

Внизу кадра ты без фона, позади запись экрана: сайт, таблица, нейросеть за работой. Формат для разборов и инструкций, зритель видит и тебя, и то, о чём ты говоришь.

Запрос к Claude Code
Открой проект moy-rolik. Собери эффект Face Over Screen на HyperFrames, формат 1080x1920. Слои снизу вверх: screen.mp4 (запись экрана, положи её в папку проекта) на весь кадр; person.mov (я без фона) в нижней половине кадра, ширина 900px, по центру, низ человека прижат к нижнему краю; субтитры по словам из транскрипта, крупно, белые с тёмной обводкой, текущее слово фиолетовое #7C3AED, над моей головой. Запись экрана растяни по высоте с кадрированием, без чёрных полос. Проверь, что руки и голова не обрезаны краем кадра. Потом сделай черновой рендер: npx hyperframes render --quality draft -o draft.mp4 и пришли мне кадры на 3, 10 и 20 секунде.
  • Приёмка: на трёх кадрах видно тебя целиком до пояса, руки внутри кадра.
  • Запись экрана читается: если на ней мелкий текст, попроси Claude увеличить нужную область записи вдвое.

5. Business Short: ты на весь экран, заголовок и парящие картинки

Ты крупно в кадре, сверху заголовок темы, по бокам появляются и плавают карточки с картинками по смыслу. Формат для экспертного ролика, где нужно удержать внимание без смены кадра.

Запрос к Claude Code
Открой проект moy-rolik. Собери эффект Business Short на HyperFrames, формат 1080x1920. Слои снизу вверх: исходное видео video.mp4 на весь кадр; заголовок «[твой заголовок в 2-4 слова]» в верхней трети, крупно, ключевое слово фиолетовым #7C3AED; три карточки 240x280 с картинками по теме ролика (сгенерируй их или возьми из папки cards), белая рамка, скругление 16px, по краям кадра, не закрывают лицо; субтитры по словам из транскрипта в нижней трети. Анимация карточек на GSAP: появление с увеличением за 0,25 секунды, лёгкий поворот от минус 8 до плюс 8 градусов, медленное покачивание вверх и вниз на 18px. Каждая карточка появляется на слове, к которому относится. Сделай черновой рендер и пришли кадры, где карточки на экране.
  • Приёмка: лицо открыто на всех кадрах, карточки по краям.
  • Картинки разные и по смыслу фраз. Три одинаковых квадрата читаются как шаблон.

6. Coaching Call: длинное видео режется на короткие

Берёшь запись эфира, созвона или длинного рассказа. Claude читает транскрипт, находит законченные куски по 20-45 секунд и делает из каждого отдельный вертикальный ролик со своим заголовком и субтитрами. Из часа эфира выходит пять-восемь коротких роликов.

Запрос к Claude Code
В папке efir лежит длинное видео efir.mp4. Сделай из него короткие ролики. 1. Распознай речь: npx hyperframes transcribe efir.mp4 -m large-v3 -l ru --json. 2. По транскрипту найди 5 самых сильных законченных мыслей длиной 20-45 секунд. Кусок начинается с цепляющей фразы и заканчивается выводом, без обрыва на полуслове. Покажи мне список: время начала и конца, первая фраза, почему этот кусок сильный. Жди моего «да». 3. После «да» вырежи каждый кусок через ffmpeg без перекодирования звука, сделай вертикаль 1080x1920 с лицом по центру. 4. Для каждого ролика собери проект HyperFrames: заголовок 3-5 слов сверху на первые 2 секунды, субтитры по словам, текущее слово фиолетовое #7C3AED. 5. Отрендери все ролики в папку shorts и пришли по одному кадру с каждого.
Шаг со списком кусков я всегда оставляю за собой. Claude хорошо находит законченные мысли, но какая из них зацепит твою аудиторию, знаешь только ты. Две минуты на просмотр списка экономят пять бракованных роликов.

7. Depth Reel: текст за головой

Крупное слово или вставка стоит позади тебя, а ты перекрываешь его головой. Глаз считывает глубину, и кадр выглядит дорогим. Секрет в стопке из первого раздела: фон, потом текст, потом ты без фона.

Запрос к Claude Code
Открой проект moy-rolik. Собери эффект Depth Reel на HyperFrames, формат 1080x1920. Слои снизу вверх: video.mp4 на весь кадр; слово «[ТВОЁ СЛОВО]» шрифтом 150px, жирным, фиолетовым #9C70ED; person.mov (я без фона) точно поверх исходника, тот же размер и позиция; субтитры по словам в нижней трети поверх всего. Слово ставь так, чтобы его верхняя половина была выше моей макушки и читалась целиком, а нижняя уходила за голову. Слово появляется на нужной фразе с плавным подъёмом на 30px за 0,3 секунды. Сделай черновой рендер и пришли кадр, где слово на экране.
  • Приёмка: слово читается, по нему понятно, что оно за головой.
  • Край вокруг волос чистый, без светлой каймы. Если кайма есть, попроси Claude повторить вырезку с ключом --quality best и выходом .webm.

8. Где этот монтаж ломается: мои промахи

Это реальные правки, которые я давал по своему ролику с этими эффектами. Проверь черновик на каждую до финального рендера.

  1. Текст глубины поставили слишком низко, и голова закрыла его целиком. Зритель видит фиолетовое пятно за затылком. Слово должно выглядывать над макушкой.
  2. При уменьшении человека для Face Over Screen обрезались кисти рук. Проверяй крайние кадры жестов, рука вылетает именно на них.
  3. В примерах эффектов показали куски того же ролика, и выглядело, будто других видео у автора нет. Для примеров бери другие свои записи, где ты в другой одежде или на другом фоне.
  4. Вместо готового эффекта на экране стоял абзац технического текста. Показывай результат крупно, объяснение зритель всё равно не прочитает.
  5. Мелкие однотипные картинки в Business Short выглядели бедно. Три яркие разные карточки сильнее пяти серых.
Порядок работы, который бережёт время: сначала черновой рендер с ключом --quality draft, просмотр по кадрам, правки, и только потом финал с --quality delivery. Финальный рендер 30 секунд идёт в разы дольше чернового.

9. Финальный рендер и звук

HyperFrames рендерит картинку. Звук из исходника надёжнее наложить отдельно, тогда он останется ровно таким, каким ты его записал.

Финал и склейка со звуком
npx hyperframes render moy-rolik --quality delivery --fps 25 -o picture.mp4 ffmpeg -i picture.mp4 -i video.mp4 -map 0:v -map 1:a:0 -c copy -shortest final.mp4
Запрос к Claude Code на приёмку
Проверь final.mp4: длительность совпадает с исходником, звук идёт синхронно, нет чёрных и застывших кадров. Вынь кадры на 5, 12, 20 и 27 секунде, посмотри каждый и скажи, где обрезаны руки или голова и где текст не читается. Ничего не исправляй без моего слова.
