Свой сервис на API Higgsfield: готовые студии из GitHub, запуск за четыре шага и проверка лицензии

Разбор того, как собрать собственный сервис на API Higgsfield: список готовых студий из открытых репозиториев с лицензиями, четыре шага запуска с рабочим кодом, таблица лицензий и пять ниш, где такой сервис можно предложить.

Проверено 21.09.2026 по официальным репозиториям Higgsfield и открытым студиям сообщества. Репозитории обновляются каждую неделю, поэтому лицензию открывай сам в день сборки.

Если хочешь запустить сервис за вечер, иди сразу ко второму и третьему разделам. Четвёртый раздел про лицензии прочитай до того, как возьмёшь за сервис первые деньги.

1. Что у Higgsfield открыто на самом деле

В ленте это подают как «открыли всё». Проверка по официальным репозиториям и материалам компании даёт более узкую и более полезную картину.

Платформа и сами модели остаются закрытыми. Открыт доступ к API: через один ключ можно отправлять запросы к более чем 50 моделям картинок и видео. Разработчикам компания отдельно даёт баланс для API, он живёт отдельно от обычной подписки. Вокруг этого лежат официальные открытые инструменты: Python SDK под Apache-2.0, Node и TypeScript SDK, консольный клиент и набор навыков для агентов под MIT.

Для тебя из этого следует одно: ты строишь свой сервис поверх их моделей. У сервиса будет свой бренд, своя ниша и свои пресеты, а генерацию будут делать их модели по твоему ключу.

Как устроен доступ, в четырёх строках

  1. Ключ создаётся в кабинете разработчика, адрес cloud.higgsfield.ai. Он состоит из двух частей: KEY_ID и KEY_SECRET, через двоеточие.
  2. Каждый запрос идёт на api.higgsfield.ai с заголовком Authorization: Key KEY_ID:KEY_SECRET.
  3. Генерация создаётся запросом на адрес модели, результат забирается опросом статуса. SDK делает опрос за тебя.
  4. Ключ живёт только на сервере. Официальный JS-клиент версии 2 отказывается работать в браузере именно по этой причине.
Три адреса, на которых держится всё остальное
POST https://api.higgsfield.ai/{model} создать генерацию GET https://api.higgsfield.ai/requests/{id}/status узнать статус и забрать результат POST https://api.higgsfield.ai/requests/{id}/cancel отменить Заголовок каждого запроса: Authorization: Key KEY_ID:KEY_SECRET

Минимальный рабочий вызов

Пример из официального Python SDK. Устанавливается командой pip install higgsfield-client, ключ кладётся в переменную окружения HF_KEY в виде KEY_ID:KEY_SECRET.

Python
import higgsfield_client # Key comes from the HF_KEY environment variable (KEY_ID:KEY_SECRET) result = higgsfield_client.subscribe( 'bytedance/seedream/v4/text-to-image', arguments={ 'prompt': 'A serene lake at sunset with mountains', 'resolution': '2K', 'aspect_ratio': '16:9', }, ) print(result['images'][0]['url'])

То же на Node и TypeScript. Устанавливается командой npm install @higgsfield/client, ключ лежит в переменной HF_CREDENTIALS.

Node, TypeScript
import { higgsfield, config } from '@higgsfield/client/v2'; // Server side only. Never put the key into browser code. config({ credentials: process.env.HF_CREDENTIALS }); const jobSet = await higgsfield.subscribe('flux-pro/kontext/max/text-to-image', { input: { aspect_ratio: '9:16', prompt: 'A beautiful sunset', safety_tolerance: 2, seed: 1234 }, withPolling: true, }); if (jobSet.isCompleted) { console.log('Image URL:', jobSet.jobs[0].results?.raw.url); }
Идентификаторы моделей в примерах взяты из официальных README. Актуальный список открой в кабинете разработчика: каталог растёт, и часть названий меняется.

2. Готовые студии на GitHub: что взять, что отложить (проверено 21.09.2026)

Я открыл каждый репозиторий, прочитал README, сверил файлы в корне и лицензию. Звёзды и даты обновления на момент проверки.

wide-trace/open-higgsfield, около 3,5 тысячи звёзд

Студия картинок и видео на Next.js 16. В каталоге 38 моделей: 8 для картинок и 30 для видео, у каждой свои настройки. Человек вводит свой ключ id:secret, сервер кладёт его в httpOnly cookie и сам ходит в API, браузер к API не обращается. Файла LICENSE в репозитории нет. Лучший образец архитектуры, чтобы понять, как всё собирается.

princejain756/Higgsfield-Open

По README почти совпадает с предыдущей студией: те же 38 моделей и та же схема с ключом пользователя. Отличие в том, что цена генерации показана прямо на кнопке, а дорогие пакеты дороже пяти долларов просят подтвердить вторым нажатием. Файла LICENSE нет.

nabilakhannn/nk-studio

Локальная студия для одного пользователя на Node 20, пять экранов: Home, Image, Video и B-roll, Library, Settings. Показывает живую цену до генерации, держит скользящий лимит трат на 30 дней, сохраняет незавершённые задачи после перезапуска. Лицензия AGPL-3.0-or-later, читай четвёртый раздел до того, как возьмёшь код.

Samin12/higgsfield-api-studio

Это навык для ChatGPT на компьютере или Codex, отдельного сайта у проекта нет. Картинки делает встроенный инструмент, видео идёт через API Higgsfield, перед каждым платным клипом показывается цена, после него чек. Лицензия MIT. Хороший образец того, как сделать защиту от лишних трат.

Официальные: higgsfield-client, higgsfield-js, cli, skills

Python SDK под Apache-2.0, SDK для Node и TypeScript (в package.json указана MIT, отдельного файла LICENSE в репозитории нет), консольный клиент и навыки под MIT. Это фундамент, на котором строится любой из вариантов выше.

Не бери clawnify/OpenStudio, если ищешь студию под Higgsfield. Он называет себя альтернативой, но работает через OpenRouter и к API Higgsfield не подключён.

3. Запуск за четыре шага

Шаги идут в том порядке, в каком их выполняют. На каждом шаге есть проверка: пока она не пройдена, дальше не иди.

Шаг 1. Клонируешь или начинаешь с нуля

Есть две дороги. Первая: склонировать любую из студий выше, запустить у себя и потрогать руками, как выглядит и как ведёт себя готовый интерфейс. Для теста хватает двух команд.

Проба студии на своём компьютере
git clone https://github.com/wide-trace/open-higgsfield.git cd open-higgsfield pnpm install pnpm dev

Студия откроется на localhost:3000, ключ вводится в окне Add key в виде id:secret. Вторая дорога: писать свой тонкий сервис поверх SDK. Для платного сервиса под своим брендом это основной путь, потому что у первых двух студий нет файла лицензии, а третья под AGPL. Тонкий сервис на SDK занимает около пятидесяти строк, пример в шаге 3.

Проверка шага: одна картинка на самой дешёвой модели вернулась ссылкой, и ты видишь её в браузере.

Шаг 2. Вставляешь свой ключ

  1. Создай ключ в кабинете разработчика и положи в переменную окружения на сервере: HF_KEY для Python, HF_CREDENTIALS для Node.
  2. Добавь файл .env в .gitignore до первого коммита. Ключ, попавший в публичный репозиторий, читают боты за минуты.
  3. Реши, чей ключ стоит в сервисе. Все студии из списка работают на ключе пользователя: человек приносит свой ключ и сам платит за вызовы. Если ключ твой, каждый клик клиента списывает баланс у тебя, поэтому нужен лимит на клиента и на день.
  4. Поставь потолок трат, пока их нечем ограничить. Образцы лежат в nk-studio (скользящий лимит на 30 дней) и в навыке Samin12 (цена показывается до платной генерации).
Проверка шага: одна платная генерация прошла, и списание видно в кабинете на ту же сумму, которую показала оценка цены.

Шаг 3. Ставишь свой бренд и пресеты

Клиенту хватает формы из одного поля, панель на 38 моделей ему ни к чему. Пресет прячет всё лишнее: он фиксирует модель, формат, шаблон промпта и оставляет клиенту только тему. Ниже тонкий сервис с одним пресетом под стоматологию, лимитом на клиента и ключом из переменной окружения. Синтаксис проверен, сам вызов API я без твоего ключа не гонял, поэтому шаг 2 идёт перед ним.

Тонкий сервис на Flask и официальном SDK
import os from datetime import date from flask import Flask, jsonify, request import higgsfield_client # reads HF_KEY from the environment app = Flask(__name__) DAILY_LIMIT = 20 # generations per client per day, protects your balance used: dict[tuple[str, date], int] = {} PRESETS = { "dental-whitening": { "model": "bytedance/seedream/v4/text-to-image", "template": "Рекламный кадр стоматологии: {topic}. Чистая светлая клиника, мягкий свет, вертикальный кадр", "aspect_ratio": "9:16", }, } @app.post("/generate") def generate(): body = request.get_json(force=True) client_id = str(body.get("client_id", ""))[:64] preset = PRESETS.get(body.get("preset")) if not client_id or preset is None: return jsonify(error="bad request"), 400 key = (client_id, date.today()) if used.get(key, 0) >= DAILY_LIMIT: return jsonify(error="daily limit reached"), 429 used[key] = used.get(key, 0) + 1 prompt = preset["template"].format(topic=str(body.get("topic", ""))[:200]) result = higgsfield_client.subscribe( preset["model"], arguments={"prompt": prompt, "aspect_ratio": preset["aspect_ratio"], "resolution": "2K"}, ) return jsonify(url=result["images"][0]["url"]) if __name__ == "__main__": app.run(port=int(os.environ.get("PORT", "8080")))
  • Название, цвет и домен свои. Логотип и название Higgsfield не используй, это чужой знак.
  • Три пресета под одну нишу для начала, не десять под все.
  • Шаблон промпта пиши так, чтобы клиент вводил одно живое предложение про свой продукт.
Проверка шага: знакомый человек из ниши сам получил кадр за одну минуту и не спросил, куда нажимать.

Шаг 4. Выкладываешь на сайт

  1. Студии на Next.js рассчитаны на Vercel. Тонкий сервис на Flask или Node ставится на любой сервер с HTTPS.
  2. Ключ на сервере лежит в переменных окружения хостинга, не в коде.
  3. Прогони один платный запрос на боевом адресе, сверь списание, только потом показывай клиенту.
  4. Сделай страницу входа или хотя бы ссылку с токеном, чтобы лимит считался на человека.
Проверка шага: ссылка открывается с телефона, один кадр собирается, лимит срабатывает на двадцать первом запросе.

4. Лицензия: что проверить до первого платного клиента

Код в открытом доступе разрешено смотреть. Продавать сервис на нём разрешено не всегда. Лицензия лежит в файле LICENSE в корне репозитория, и читается она за две минуты.

MIT

Самая свободная. Можно менять, встраивать в платный сервис и продавать. Условие одно: сохранить текст лицензии и имя автора в своей копии.

Apache-2.0

Тоже разрешает коммерческое использование. Нужно сохранить уведомления об авторстве и отметить, что ты менял. Даёт отдельную патентную защиту, поэтому официальные SDK выпущены именно под ней.

AGPL-3.0

Самая коварная для платного сервиса. Если люди работают с твоей изменённой версией по сети, ты обязан отдать им исходный код этой версии. Закрытый сервис под своим брендом на таком коде не получится. У nk-studio именно такая лицензия.

Файла LICENSE нет

По умолчанию все права остаются за автором. Смотреть код и форкать в пределах GitHub можно, встраивать в свой платный продукт без письменного разрешения нельзя. Так обстоит дело у обеих студий с Next.js из второго раздела. Выход: написать автору в Issues и получить разрешение письмом, либо писать свой слой на SDK.

Шесть вопросов перед запуском

  1. Есть ли в корне файл LICENSE и какая там лицензия.
  2. Указана ли в README отдельная оговорка про название, логотип и оформление. У nk-studio такая есть: название и визуальный стиль автору принадлежат, даже если код разрешено менять.
  3. Остались ли в интерфейсе чужие имена, логотипы и ссылки, которые надо убрать.
  4. Что написано в условиях самого API Higgsfield про перепродажу доступа и про обязательные ограничения на содержимое. Их текст я сюда не переписываю, потому что он меняется: открой актуальную версию в кабинете перед тем, как брать деньги.
  5. Кому в договоре с клиентом принадлежат готовые ролики и кто отвечает, если результат нарушил чужие права.
  6. Какие данные клиента проходят через сервис и где они хранятся.
Я не юрист. Для договора с клиентом и для условий перепродажи нужен человек, который эти условия читает профессионально. Этот раздел отвечает на вопрос, какие вопросы ему задать.

5. Пять ниш и первое сообщение клиенту

Ниша выбирается по одному признаку: человеку регулярно нужны короткие визуалы под его продукт, а снимать самому дорого или лень. Спрос в этих нишах я проверенным числом подтвердить не могу, поэтому в конце раздела стоит способ проверить его за неделю.

Стоматологии и клиники

Вводят: услугу, например отбеливание. Получают: вертикальный рекламный кадр или ролик на пятнадцать секунд. Пресет держит светлую клинику и спокойную подачу. Ограничение: не показывать результаты лечения, которых не было.

Кофейни и небольшие рестораны

Вводят: новое блюдо или напиток. Получают: кадр для меню, сторис и афиши. Пресет держит фирменные цвета заведения. Повод возвращаться каждую неделю: сезонные позиции.

Фитнес-студии и тренеры

Вводят: тип занятия и время. Получают: анонс расписания, кадры для рассылки. Пресет держит одну визуальную рамку для всех занятий.

Агенты по недвижимости

Вводят: адрес и фото объекта. Получают: ролик-прогулку по комнатам из готовых фото, видеомодель оживляет статичные кадры. В открытом доступе уже лежат навыки под эту задачу, то есть путь проверен другими.

Продавцы на маркетплейсах

Вводят: фото товара. Получают: несколько рекламных кадров и карточек с разным фоном. Официальный набор навыков Higgsfield содержит отдельный навык под карточки маркетплейсов, значит платформа сама считает эту задачу типовой.

Как проверить нишу за неделю

  1. Выбери одну нишу и найди десять заведений в своём городе.
  2. Каждому отправь сообщение ниже и приложи один готовый кадр под его бизнес. Кадр делается за минуту на самой дешёвой модели.
  3. Считай ответы. Три и больше живых «покажи ещё» из десяти дают основание собирать сервис. Два и меньше означают, что менять надо нишу или подачу, сам сервис остаётся.
Первое сообщение владельцу
Здравствуйте, [ИМЯ]. Я сделал небольшой сервис, который за минуту собирает рекламные кадры и короткие ролики под [НИША]: вы вводите тему, например «[ПРИМЕР ТЕМЫ]», и получаете готовый вертикальный кадр. Могу за один вечер сделать пробные [3 КАДРА] под вашу [КЛИНИКУ / КОФЕЙНЮ / СТУДИЮ] бесплатно, чтобы вы посмотрели на результат. Если понравится, обсудим ежемесячный формат. Подойдёт?

Формат оплаты для сервиса такой: ежемесячная подписка на пресеты и на определённое число кадров в месяц. Цену назначай после пробного месяца, когда видишь, сколько генераций съедает один клиент и сколько стоит один вызов по оценке цены в API. Оценка цены доступна до генерации, поэтому маржу видно заранее.

6. План на сегодня

Восемьдесят минут вместо недели раздумий.

  1. Заведи ключ в кабинете разработчика и положи его в переменную окружения (десять минут).
  2. Запусти пример из первого раздела и получи первую картинку (пятнадцать минут).
  3. Склонируй студию из второго раздела и посмотри на неё локально (двадцать минут).
  4. Выбери одну нишу из пятого раздела и напиши один пресет (двадцать минут).
  5. Отправь первое сообщение одному владельцу из ниши с готовым кадром (пятнадцать минут).
Если на каком-то шаге получилось не то, что здесь описано, пришли мне скрин и слово ФОРК. Список репозиториев меняется.
