Claude снимает кино: 7 репозиториев, установка и 5 промптов

Семь открытых репозиториев, в которых Claude делает видео кодом: киностили, моушн-дизайн, рисованные мультики, клипы под песню и библиотеки промптов. Плюс установка по шагам и пять промптов, чтобы собрать первый вертикальный ролик под рилс.

Внутри: что нужно для старта, 7 репозиториев с тем, как запустить каждый, 5 промптов под рилсы и честно про лимиты. Читается за 7 минут. Звёзды и описания репозиториев сверены на GitHub 25.10.2026.

Как это работает

Claude не генерирует видео, как нейросети для роликов. Он пишет код, который рисует каждый кадр, потом прогоняет кадры через браузер и собирает MP4.

  • Картинка получается чистой: текст на экране без ошибок, логотипы и цифры такие, как ты написал.
  • Ролик можно править словами: «сделай фон темнее», «ускорь вторую сцену», и он пересоберёт только это.
  • Сильнее всего выходят моушн-дизайн, мультики, объясняющие ролики и клипы с текстом. Живого человека в кадре так не снимешь, для этого нужны видеонейросети.

Что нужно до старта

Один раз ставишь Claude Code и три программы, дальше всё запускается одной командой.

  1. Подписка Claude Pro или Max, либо ключ API. Бесплатный тариф Claude Code не включает.
  2. Claude Code. На Mac и Linux команда ниже в Терминале, на Windows в PowerShell. Потом открой новое окно и набери claude, он попросит войти в аккаунт через браузер.
  3. Node.js 20 или новее (nodejs.org), ffmpeg (ffmpeg.org) и Google Chrome. Не хочешь ставить сам, попроси Claude: «проверь, установлены ли node, ffmpeg и chrome, и поставь недостающее».
  4. Для lemo-opuscar ещё Python 3.11 или новее.
Установка Claude Code на Mac и Linux
curl -fsSL https://claude.ai/install.sh | bash
Установка Claude Code на Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
Официальная инструкция с запасными способами установки: code.claude.com/docs/en/setup. Claude работает не во всех странах, список есть на сайте Anthropic, проверь его до оплаты.

Семь репозиториев

Ссылки ведут на GitHub. Каждый открывается в браузере, код можно скачать кнопкой Code или командой git clone.

1. lemo-opuscar, 59 киностилей

github.com/lemomo-ai/lemo-opuscar. Скилл для Claude Code: 59 стилей, к каждому промпт стиля и пример фильма, сделанного целиком в коде. Выбираешь стиль, рассказываешь историю, Claude режиссирует. Можно сделать и свой стиль. Около 7 тысяч звёзд, лицензия MIT.

2. mg-styles-15, моушн-дизайн

github.com/Vincentwei1021/mg-styles-15. 15 стилей, на каждый ролик на 10 секунд, полный промпт и весь код, музыка тоже синтезирована кодом. Галерея с плеером: vincentwei1021.github.io/mg-styles-15. MIT.

3. ClaudeAnimationBase, мультики

github.com/JohnHeibel/ClaudeAnimationBase. Стартовый набор для рисованной анимации: персонаж, 31 сыгранная эмоция и гайд для модели ANIMATION_GUIDE.md. Claude сам делает раскадровку, проверяет кадры и пишет out/video.mp4. MIT.

4. PDoomVideo, клип-мультик

github.com/JohnHeibel/PDoomVideo. Исходник клипа на песню «I'm Upping My P(doom)». Автор дал только персонажа и одну строку «сделай каждую строчку песни интересной», сцены придумал Claude за две генерации. Ценен как пример и как гайд по анимации.

5. pdoom-video, клип с текстом песни

github.com/mexicat/pdoom-video. Та же песня, другой клип: каждое слово на экране попадает в голос, экспорт 1080p60 или 4K60. Тяжёлый для домашнего компьютера, полезен как образец синхронного текста. MIT.

6. opus-video-prompts, 18 промптов

github.com/joeseesun/opus-video-prompts. 18 полных промптов и 54 кейса с ссылками на оригиналы, советы по рендеру. Описание на китайском, промпты на английском, браузер переведёт страницу в один клик.

7. awesome-opus5-5-videos, 703 промпта

github.com/yihui-dev/awesome-opus5-5-videos. Самая большая подборка роликов, которые люди сделали в Claude, к каждому промпт или ссылка на оригинальный пост. Около 10,8 тысячи звёзд, MIT.

Установка lemo-opuscar (в Терминале)
claude plugin marketplace add lemomo-ai/lemo-opuscar claude plugin install lemo-opuscar@lemolab
Запуск набора для мультиков
git clone https://github.com/JohnHeibel/ClaudeAnimationBase cd ClaudeAnimationBase claude

Пять промптов для первого ролика

Все под вертикаль 9:16. Скобки меняешь на своё, остальное оставляешь.

Промпт 1: фильм в киностиле (lemo-opuscar)
/lemo-opuscar:lemo-opuscar Сними вертикальный фильм 9:16 на 20 секунд для моего рилса. Тема: [о чём ролик, одной фразой]. Зритель: [кто он и что у него болит]. Стиль возьми из библиотеки, предложи мне три подходящих на выбор и подожди ответа. Первые 3 секунды крупный текст хука: [твоя первая фраза]. В конце кадр с текстом: [что человек должен сделать]. Перед рендером покажи раскадровку и контактный лист кадров.
Промпт 2: заставка блога (mg-styles-15)
Открой папку репозитория mg-styles-15 и прочитай промпт стиля [название стиля из списка]. Сделай по нему заставку для моего блога: вертикаль 9:16, 1080x1920, 8 секунд. Текст на экране: [имя или название блога] и [одна строка, чем ты полезен]. Цвета: [2-3 цвета]. Музыку и звуки синтезируй в коде, как в оригинале. Сначала покажи 3 ключевых кадра, потом рендери MP4.
Промпт 3: мультик с персонажем (ClaudeAnimationBase)
Read ANIMATION_GUIDE.md. Сделай мультик 9:16 на 15 секунд с персонажем из набора. Сюжет: [персонаж пытается сделать то, с чем мучается мой зритель, например снять рилс с первого дубля], в конце он справляется благодаря [твоему совету одной фразой]. Используй 3-4 эмоции из набора. Сначала раскадровка, потом сцена за сценой, проверь себя по контактным листам и запиши out/video.mp4.
Промпт 4: текст под твой голос, слово в слово
Вот мой текст для рилса на 20 секунд и аудиофайл с моим голосом: [путь к файлу]. Сделай вертикальное видео 9:16, где каждое слово появляется на экране ровно в момент, когда я его произношу, как в клипе pdoom-video: крупная типографика, 2-3 смены фона, ключевые слова выделены цветом [цвет]. Каждый кадр должен зависеть только от времени, чтобы превью и рендер совпадали. Рендер MP4 1080x1920.
Промпт 5: чужой удачный ролик под твою нишу
Вот промпт из библиотеки awesome-opus5-5-videos: [вставь промпт]. Перепиши его под мою нишу: [чем ты занимаешься], мой зритель [кто он]. Сохрани приём и ритм оригинала, поменяй тему, текст на экране и финальный кадр. Формат 9:16, до 20 секунд, первые 3 секунды хук [твоя первая фраза]. Выдай готовый промпт, потом выполни его и отрендери MP4.

Честно про лимиты

Чтобы первый ролик не стал последним.

  • Короткий ролик на 10-20 секунд обычно укладывается в обычную подписку. Клип на несколько минут может съесть заметную часть недельного лимита Max, по опыту авторов из opus-video-prompts.
  • Почти всё, что называют «с первого раза», на деле прошло два-три круга правок. Закладывай их сразу.
  • Первый рендер делай коротким и в 1080p. 4K оставь на финал, он идёт в разы дольше.
  • Для рилса ролик должен цеплять в первые 3 секунды: крупный текст хука и движение с первого кадра.
