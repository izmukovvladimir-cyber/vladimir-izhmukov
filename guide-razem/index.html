Четыре коннектора для Клода: команды установки и проверка каждого

Четыре коннектора, которые превращают Клода из собеседника в работника: свежий поиск по интернету, чтение любого сайта, живой браузер и подключение к сотне сервисов, которыми ты уже пользуешься. Внутри команды установки дословно, честные условия по деньгам и проверка, что каждый реально включился.

Читается за 8 минут. Внутри четыре команды установки, промпт-проверка на каждый коннектор и разбор частых ошибок. Условия сервисов проверены 25 августа 2026 по их официальным страницам.

Ставь по одному и после каждого прогоняй проверочный запрос из этого файла. Так ты сразу видишь, какой коннектор поднялся, и не разбираешь потом четыре молчащих сразу. Начни с Playwright и Firecrawl: они дают результат в первые пять минут и не требуют платного ключа.

Почему без коннекторов модель работает вполсилы

Сам по себе Клод знает только то, что было в его обучении, и не видит ни сегодняшнюю страницу, ни твой рабочий сервис. Коннектор это мост наружу: он даёт модели право сходить куда-то и вернуться с фактами.

  • Без коннектора модель отвечает по памяти, и на свежем вопросе она честно угадывает. С поиском она отвечает по сегодняшней выдаче.
  • Без коннектора ты копируешь ей текст сайта руками. С коннектором она забирает страницу сама, включая ту, что открывается только через браузер.
  • Без коннектора она пишет тебе инструкцию «зайди и нажми». С браузерным коннектором она заходит и нажимает сама.
  • Без коннектора твои рабочие сервисы живут отдельно от неё. С подключением к ним она собирает данные из почты, таблиц и мессенджеров в одном ответе.
Порядок в этом файле выбран по цене входа. Playwright и Firecrawl поднимаются без карты и дают результат сразу. Perplexity просит платный ключ. Composio ключа не просит, но подключение каждого сервиса идёт через отдельный вход в него.

Коннектор 1. Playwright, живой браузер

Официальный проект Microsoft, лицензия Apache 2.0, ключ не нужен. Даёт модели управлять реальной страницей: заполнять формы, нажимать кнопки, проверять, что сайт работает.

Промпт
claude mcp add playwright npx @playwright/mcp@latest
Это команда для Claude Code в терминале. В настольном приложении тот же коннектор добавляется через файл конфигурации, блок ниже кладётся в mcpServers.
Промпт
{"mcpServers": {"playwright": {"command": "npx", "args": ["@playwright/mcp@latest"]}}}
Промпт
Проверка. Открой через браузер страницу example.com, прочитай заголовок первого уровня и верни мне его текст. Если браузер не поднялся, скажи об этом прямо и не выдумывай ответ.

Коннектор 2. Firecrawl, чтение любого сайта

Официальный сервер сервиса Firecrawl. Забирает содержимое страницы или целого раздела и отдаёт модели чистым текстом. На бесплатном тарифе 1000 обращений в месяц, карта не нужна, это подтверждено их страницей цен.

Промпт
npx -y firecrawl-mcp
С личным ключом (личный кабинет firecrawl.dev) команда выглядит так, ключ начинается на fc-.
Промпт
env FIRECRAWL_API_KEY=fc-ТВОЙ_КЛЮЧ npx -y firecrawl-mcp
Промпт
Проверка. Забери страницу моего конкурента целиком и собери из неё таблицу: заголовок, обещание, цена, призыв к действию. Ссылку я дам следующим сообщением. Ничего не додумывай, бери только то, что есть на странице.

Коннектор 3. Perplexity, свежий поиск и разбор

Официальный сервер платформы Perplexity. Даёт поиск по сегодняшнему интернету со ссылками на источники, то есть закрывает главную слабость модели: устаревшие знания.

Промпт
claude mcp add perplexity --env PERPLEXITY_API_KEY="ТВОЙ_КЛЮЧ" -- npx -y @perplexity-ai/mcp-server
Ключ берётся в консоли console.perplexity.ai. Про деньги честно: на странице цен описаны только платные тарифы с оплатой по объёму запросов, бесплатного уровня для этого ключа я там не нашла. Если платить пока не хочешь, ставь первые два коннектора, они закрывают большую часть работы.
Промпт
Проверка. Найди, что писали за последние семь дней про мою тему, и верни пять фактов, у каждого рядом ссылка на источник и дата. Всё, что не подтверждается ссылкой, отбрасывай.

Коннектор 4. Composio, вход в сервисы, которыми ты уже пользуешься

Подключает модель к сотням сторонних сервисов сразу: почта, таблицы, заметки, мессенджеры, задачи. Вместо установки каждого по отдельности ты добавляешь один адрес и дальше входишь в нужный сервис по кнопке.

Промпт
https://connect.composio.dev/mcp
Добавляется как коннектор по протоколу HTTP. Заголовки авторизации прописывать не надо, вход в каждый сервис идёт по кнопке при первом обращении, так написано в их же инструкции. Условия бесплатного уровня самой платформы на их странице не раскрыты, поэтому цену уточняй в кабинете при подключении.
Промпт
Проверка. Покажи список сервисов, к которым у тебя сейчас есть доступ через Composio. Ничего не подключай без моего слова, просто перечисли.
С чего начать в соцсетях

Один запрос, который ставит всё сразу

Если возиться с четырьмя командами не хочется, отдай эту работу самому Клоду. Запрос ниже кладётся в Claude Code, дальше он ставит коннекторы по очереди и сам показывает, что поднялось.

Промпт
Поставь мне четыре коннектора по очереди и после каждого проверь, что он отвечает. 1. Playwright: claude mcp add playwright npx @playwright/mcp@latest 2. Firecrawl: npx -y firecrawl-mcp 3. Perplexity: claude mcp add perplexity --env PERPLEXITY_API_KEY="КЛЮЧ" -- npx -y @perplexity-ai/mcp-server 4. Composio: добавь как HTTP-коннектор адрес https://connect.composio.dev/mcp без заголовков авторизации. Правила работы. Ставь строго по одному. После каждого выведи список активных коннекторов и напиши словами, поднялся он или нет. Если какой-то не поднялся, покажи текст ошибки целиком и предложи одно исправление, дальше жди моего слова. Ключей у тебя нет, где нужен ключ, останавливайся и проси его у меня.
Ключи в этот запрос не вставляй заранее и никуда не выкладывай. Клод попросит их сам в нужный момент.

Что проверить перед тем, как считать работу сделанной

Коннектор считается живым только после того, как он вернул результат. Установка без проверки это половина дела: чаще всего он ставится, но молчит из-за ключа или версии.

  • Список коннекторов показывает все четыре, и рядом стоит признак активности.
  • Playwright открыл страницу и вернул заголовок. Молчит, значит браузер не установился, помогает повторный запуск команды.
  • Firecrawl вернул текст страницы. Пришло сообщение о лимите, значит коннектор жив, но обращения кончились. Уперся в лимит, значит бесплатные обращения кончились, ключ решает.
  • Perplexity вернул факты со ссылками и датами. Вернул общие слова без ссылок, значит запрос ушёл мимо коннектора.
  • Composio показал список сервисов. Список пустой, значит вход ни в один сервис ещё не выполнен.
Если модель отвечает уверенно и без ссылок, а коннектор при этом не поднялся, она отвечает по памяти. Это самая дорогая ошибка в работе с коннекторами: ответ выглядит рабочим и оказывается выдуманным. Поэтому в каждый проверочный запрос выше вписана строка про честное признание отказа.

Частые ошибки

Собрано по разбору чужих установок и по своим граблям.

  • Ставят все четыре разом и получают четыре молчащих коннектора. Разобрать такое сложнее, чем поставить заново по одному.
  • Путают приложение и Claude Code. Команда через терминал работает в Claude Code, в настольном приложении коннектор добавляется через файл конфигурации.
  • Кладут ключ прямо в текст запроса и отправляют его в общий чат. Ключ после этого считается утёкшим и его надо перевыпускать.
  • Ждут от Composio, что он подключит сервисы сам. Он даёт вход, а нажать на вход в каждый сервис надо один раз руками.
  • Проверяют коннектор вопросом «ты подключён». Модель отвечает «да» и в том случае, когда коннектор мёртв. Проверять надо действием: попроси открыть страницу и вернуть заголовок.
