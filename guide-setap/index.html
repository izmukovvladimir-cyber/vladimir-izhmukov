Сетап Claude Code: 42 дополнения по пяти отделам с командой установки и официальной ссылкой

Все 42 дополнения из карусели с командой установки и официальной ссылкой на каждое. Команды взяты из официальных README и документации, каждую ссылку мы открыли 12 ноября 2026 года. Где официальной команды под Claude Code нет, так и написано, и дана страница, откуда ставить.

Внутри: 42 дополнения к Claude Code по пяти отделам (сборка, дизайн и видео, ресёрч и тексты, контент, офис), у каждого роль, что делает, команда установки и официальная ссылка. Плюс где вводить команды и с какого отдела начать.

Как пользоваться этим списком

Ставить все 42 разом не нужно, каждое дополнение занимает место в памяти Claude. Начни с отдела под задачу, которая у тебя горит сейчас.

  • Строки, которые начинаются с косой черты (/plugin ...), вводишь внутри Claude Code, в окне чата с ним.
  • Всё остальное (claude mcp add, npx, npm, brew, pip) вводишь в обычном терминале, в той же папке, где запускаешь Claude Code.
  • Для npx и npm нужен Node.js (номер 41), для pip и uv нужен Python (номер 33). Поставь их первыми.
  • После подключения сервера командой claude mcp add зайди в Claude Code, введи /mcp и проверь, что сервер подключён. Где нужен вход, там же жмёшь Authenticate.
  • Плагины и скиллы из чужих репозиториев получают доступ к твоему компьютеру. Мы дали только официальные источники, и всё равно ставь то, что реально будешь использовать.
С чего начать, если ты не программист: Superpowers (1), Claude in Chrome (19), Notion (34) или Gmail (35). Если делаешь ролики: ffmpeg (16), Remotion (15) и Whisper (32).

Отдел 1. Сборка и тесты: 8 дополнений

Спланировать, собрать, проверить и выложить.

01. Superpowers, главный планировщик

Набор скиллов, который заставляет Claude сначала продумать задачу и план, потом писать код, проверять и только после этого говорить «готово».

Superpowers: установка
/plugin install superpowers@claude-plugins-official
Superpowers: официальная страница

02. gstack, ведущий разработчик

Набор скиллов Гарри Тана под полный цикл разработки: планирование, ревью, браузер для проверки, выпуск. Нужны Git и Bun.

gstack: установка
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup
gstack: официальная страница

03. graphify, картограф кода

Превращает проект с документами и схемами в граф знаний, по которому Claude быстро находит нужное. Нужен Python 3.10+ и uv.

graphify: установка
uv tool install graphifyy graphify install
После установки в Claude Code пишешь /graphify . и он строит граф текущей папки.
graphify: официальная страница

04. GitHub CLI, релиз-менеджер

Команда gh: пул-реквесты, задачи, релизы прямо из терминала. Claude Code умеет им пользоваться сам.

GitHub CLI: установка
Mac: brew install gh Windows: winget install --id GitHub.cli --source winget Скилл для агента: gh skill install cli/cli gh --scope user
GitHub CLI: официальная страница

05. Vercel, инженер запуска

Выкладывает сайт в интернет одной командой. Плагин добавляет Claude знания о Vercel и готовые команды.

Vercel: установка
npm i -g vercel npx plugins add vercel/vercel-plugin
Внутри Claude Code плагин ставится и так: /plugin install vercel
Vercel: официальная страница

06. Playwright, тестировщик

Даёт Claude настоящий браузер: открыть страницу, нажать кнопки, заполнить форму и проверить, что всё работает.

Playwright: установка
claude mcp add playwright npx @playwright/mcp@latest
Playwright: официальная страница

07. Codex, второй ревьюер

Официальный плагин OpenAI: прямо из Claude Code отдаёшь код на проверку Codex и получаешь второе мнение от другой модели.

Codex: установка
/plugin marketplace add openai/codex-plugin-cc /plugin install codex@openai-codex
Нужен установленный Codex CLI (npm install -g @openai/codex) и вход в аккаунт ChatGPT или ключ OpenAI.
Codex: официальная страница

08. Claude HUD, монитор сессий

Строка состояния внизу Claude Code: сколько контекста занято, какие инструменты работают, что делают агенты.

Claude HUD: установка
/plugin marketplace add jarrodwatts/claude-hud /plugin install claude-hud
Claude HUD: официальная страница

Отдел 3. Ресёрч и тексты: 8 дополнений

Видеть весь интернет и писать тексты, которые звучат как ты.

18. Perplexity, искатель фактов

Поиск с ответами и ссылками на живые источники. Нужен ключ API Perplexity, его берёшь в кабинете Perplexity.

Perplexity: установка
claude mcp add perplexity --env PERPLEXITY_API_KEY="your_key_here" -- npx -y @perplexity-ai/mcp-server
Вместо your_key_here вставь свой ключ. Кавычки оставь.
Perplexity: официальная страница

19. Claude in Chrome, веб-ассистент

Claude ходит по сайтам в твоём Chrome, кликает, заполняет формы и видит то, что видишь ты, со всеми входами в аккаунты. Нужен прямой план Anthropic (Pro, Max и выше).

Claude in Chrome: установка
claude --chrome
Сначала поставь расширение Claude из Chrome Web Store, ссылка на странице документации. Внутри сессии /chrome показывает статус и переподключает браузер.
Claude in Chrome: официальная страница

20. Firecrawl, читатель сайтов

Превращает любую страницу в чистый текст без меню и рекламы, умеет обходить сайт целиком. Вход через аккаунт Firecrawl в браузере.

Firecrawl: установка
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
Адрес сервера взят из документации Firecrawl, команда это стандартный формат подключения сервера в Claude Code. После добавления в Claude Code пишешь /mcp и входишь в аккаунт.
Firecrawl: официальная страница

Apify: установка

Apify: официальная страница

Картинки, голос, графика и файлы к ним.

26. GPT Image, создатель картинок

Модель картинок OpenAI. Отдельного плагина для Claude Code у OpenAI нет, работает через их API по ключу.

Ставится с официального сайта: берёшь ключ OpenAI, кладёшь его в переменную окружения и просишь Claude Code написать короткий скрипт по этой документации.
GPT Image: официальная страница

27. Nano Banana, фоторетушёр

Модели картинок Google в Gemini API: правят фото по одной фразе. Работают по ключу Gemini API.

Ставится с официального сайта: ключ берёшь в Google AI Studio, дальше Claude Code пишет вызов по этой документации.
Nano Banana: официальная страница

28. ElevenLabs, диктор

Озвучка сценария голосом, клонирование голоса, звуковые эффекты. У ElevenLabs свой сервер для агентов, вход через аккаунт.

ElevenLabs: установка

Адрес сервера из документации ElevenLabs, команда это стандартный формат Claude Code. Старый локальный сервер ElevenLabs больше не поддерживается.
